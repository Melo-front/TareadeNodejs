Node.js

¿Qué es Node.js?

Node.js es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Fue creado para desarrollar aplicaciones del lado del servidor, como páginas web, APIs y sistemas en tiempo real. NodeJS utiliza el motor V8 de Google Chrome para ejecutar JavaScript de manera rápida y eficiente

  • Crear servidores web.
  • Desarrollar APIs REST.
  • Aplicaciones en tiempo real como chats.
  • Automatización de tareas.
  • Manejo de bases de datos.

Ejemplo


const http = require('http');

const servidor = http.createServer((req, res) => {
res.write('Hola Mundo');
res.end();
});

servidor.listen(3000);

Comando npm

¿Qué es el comando npm?

npm significa “Node Package Manager”. Es el administrador de paquetes de NodeJS y sirve para instalar librerías, dependencias y herramientas para proyectos JavaScript. Con npm se pueden descargar paquetes creados por otros desarrolladores y también administrar las dependencias del proyecto.

  • Instalación: Se hace mediante la terminal con el comando npm install nombre-del-paquete.
  • Comunidad: Existen millones de paquetes gratuitos disponibles para ahorrarte tiempo.

Comandos básicos de npm


npm init

npm install express

npm start

npm uninstall nombre-paquete

Express.js

¿Qué es Express.js?

Express.js es un framework de NodeJS que facilita la creación de servidores y aplicaciones web. Ayuda a manejar rutas, peticiones HTTP y middleware de manera más sencilla. Express es uno de los frameworks más utilizados en NodeJS.

Características de Express

  • Manejo de rutas.
  • Creación de APIs.
  • Middleware.
  • Manejo de peticiones y respuestas HTTP.
  • Integración con bases de datos.

Ejemplo


const express = require('express');

const app = express();

app.get('/', (req, res) => {
    res.send('Hola desde Express');
});

app.listen(3000, () => {
    console.log('Servidor ejecutándose');
});

¿Cómo usar Express.js?

Crear una carpeta del proyecto


    mkdir mi-proyecto

Entrar a la carpeta


    cd mi-proyecto

Inicializar npm


    npm init -y

Installar express


    npm install express

Crear un archivo index.js


const express = require('express');

const app = express();

app.get('/', (req, res) => {
    res.send('Hola desde Express');
});

app.listen(4000, () => {
    console.log('Servidor ejecutándos http://localhost:4000');
});

Ejecutar el proyecto


        node index.js

package.json

¿Qué es el package.json?

El archivo package.json es el archivo principal de configuración de un proyecto NodeJS. Contiene información del proyecto y las dependencias instaladas.

Información que contiene

  • Nombre del proyecto.
  • Versión.
  • Dependencias.
  • Scripts.
  • Autor.
  • Licencia.

Funciones del package.json

  • Administrar dependencias.
  • Ejecutar scripts.
  • Configurar el proyecto.
  • Compartir proyectos fácilmente.

Ejemplo


{
  "name": "mi-proyecto",
  "version": "1.0.0",
  "main": "index.js",
  "scripts": {
    "start": "node index.js"
  },
  "dependencies": {
    "express": "^4.18.2"
  }
}
